Барои харидорон

SSBOSS-ро тавассути барнома (iOS/Android) ё сайт истифода баред. Як ҳисоб барои ҳарду.

Оғози кор

Харидор

Барномаро аз App Store ё Google Play боргирӣ кунед. Дар саҳифаи асосӣ маҳсулотро бинед.

Каталог

«Каталог» → категорияро интихоб кунед. Дил — дӯстдошта, сабад — ба корзина илова кунед.

Сабад ва фармоиш

Маҳсулотро ба сабад илова кунед, фармоиш диҳед. Дар «Профил» → «Фармоишҳои ман» ҳолатро пайгирӣ кунед.

Sellers

Барои фурӯшандагон

Мағозаро тавассути панели маъмурии SSBOSS идора кунед.

Коркарди фармоишҳо

Фурӯшанда

Дар админка «Фармоишҳо»-ро кушоед. Маълумоти харидор, ададҳо ва статусро бинед. Статусро навсозӣ кунед.

Чӣ тавр фурӯшанда шавем?

  • Дар сайт «Стать продавцом» ё ба дастгирӣ муроҷиат кунед
  • Баъд аз тасдиқ — дастрасӣ ба админка
