Architecture

Архитектура системы

SSBOSS — монорепозиторий: Flutter mobile app (lib/) + Laravel 11 API и собранные Nuxt SPA (server_code/). Все клиенты обращаются к единому REST API.

Flutter App

Dio-клиент, Riverpod, GoRouter. Feature-модули в lib/features/* с repo-слоем API.

Laravel API

Маршруты в server_code/routes/api.php. Passport OAuth2 для user и admin guards.

Nuxt SPA

Собранная витрина (_nuxt/) и админка (admin/) — используют тот же API.

REST API

Обзор API

  • Базовый URL: https://ssboss.shop/api/v1
  • Формат: JSON, заголовок Accept: application/json
  • Rate limit: 60 запросов/мин на IP или пользователя
  • Файл маршрутов: server_code/routes/api.php
  • Группы: /api/v1/* (storefront/mobile), /api/admin/* (backoffice)
GET  /api/v1/home
GET  /api/v1/products?page=1
GET  /api/v1/product/{id}
POST /api/v1/user/signin
POST /api/v1/cart/action?user_token=g_...

Admin API

Административный API

Префикс /api/admin/. Вход: POST /api/admin/login → Bearer с scope:admin. CRUD для товаров, категорий, заказов, пользователей, настроек, баннеров, продавцов, POS и др. 

POST /api/admin/login
GET  /api/admin/product/all
POST /api/admin/order/update-status

Flutter

Мобильный API-клиент

Dio setup

  • lib/core/api_client.dart — shared Dio instance
  • lib/core/config.dart — baseUrl, tokens, imageUrl()
  • Interceptor добавляет Authorization: Bearer
  • Timeout: 15 сек connect/receive

Конфигурация URL

  • Default: https://ssboss.shop/api/v1
  • Override: .env → API_BASE_URL
  • Fallback: assets/app_config.json
  • CDN: CDN_BASE_URL для медиа

Токены

  • bearer_token — общий Passport token
  • mobile_bearer_token — приоритет для mobile
  • guest_token — формат g_{timestamp}_{random}
  • Хранение: SharedPreferences

Feature modules

  • lib/features/auth/repo/auth_api.dart
  • lib/features/catalog/repo/catalog_api.dart
  • lib/features/cart/repo/cart_api.dart
  • lib/features/orders/repo/order_api.dart
  • State: Riverpod, routing: GoRouter

Setup

Локальная настройка

Laravel (server_code)

  • Скопировать .env.example → .env
  • Настроить DB_* (MySQL по умолчанию)
  • php artisan key:generate
  • php artisan migrate
  • Passport keys: php artisan passport:install

Flutter

  • flutter pub get
  • В .env: API_BASE_URL, AES_KEY, AES_IV
  • iOS: cd ios && pod install
  • Firebase: lib/firebase_options.dart
