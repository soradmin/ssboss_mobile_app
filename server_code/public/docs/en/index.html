SSBOSS Technical Documentation

REST API, architecture, repository layout, and Flutter ↔ Laravel integration. End-user guides for buyers and sellers are published separately.

Base URL: https://ssboss.shop/api/v1

Architecture REST API Authentication Catalog Cart Orders Profile & lists Admin API Flutter client Laravel Repository Local setup Tech stack

Architecture

System overview

Monorepo: Flutter app (lib/) + Laravel 11 API and pre-built Nuxt SPAs (server_code/). All clients share one REST API.

Flutter

Dio client, Riverpod, GoRouter. Features in lib/features/*.

Laravel API

Routes in routes/api.php. Passport OAuth2.

Nuxt SPA

Storefront (_nuxt/) and admin (admin/).

REST API

API overview

Base: https://ssboss.shop/api/v1

Format: JSON, Accept: application/json

Routes file: server_code/routes/api.php

Groups: /api/v1/* (mobile/storefront), /api/admin/* (backoffice)

Admin

Admin API

Prefix /api/admin/. Login: POST /api/admin/login. Full CRUD for catalog, orders, settings, sellers.

Flutter

Mobile API client

Core files

  • lib/core/api_client.dart — Dio + Bearer interceptor
  • lib/core/config.dart — URLs, tokens
  • Guest token: g_{timestamp}_{random}

Config

  • Default API: https://ssboss.shop/api/v1
  • Override via .env → API_BASE_URL

Backend

Laravel backend

  • server_code/routes/api.php
  • Guards: user, admin (Passport)
  • Rate limit: 60 req/min

Repository

Folder structure

lib/           → Flutter app
server_code/   → Laravel + Nuxt builds
  routes/api.php
  public/docs/   → this documentation

Setup

Local development

Laravel

  • .env.example → .env, configure DB
  • php artisan migrate
  • php artisan passport:install

Flutter

  • flutter pub get
  • .env: API_BASE_URL, AES_KEY, AES_IV

Stack

Technologies

  • Flutter 3, Riverpod, GoRouter, Dio

Backend

  • Laravel 11, PHP 8.2, Passport
