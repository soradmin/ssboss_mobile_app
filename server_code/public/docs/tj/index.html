For Developers

Ҳуҷҷатгузории техникии SSBOSS

REST API, архитектура, сохтори репозиторий ва интегратсияи Flutter бо Laravel. Дастури истифодабарандагон (харидорон/фурӯшандагон) алоҳида нашр мешавад.

Base URL: https://ssboss.shop/api/v1

Архитектура REST API Аутентификатсия Каталог Сабад Фармоишҳо Flutter Танзим Технология

Architecture

Архитектураи система

Монорепозиторий: Flutter (lib/) + Laravel 11 API ва Nuxt SPA (server_code/). Ҳамаи клиентҳо ба як REST API муроҷиат мекунанд.

REST API

Обзори API

Base: https://ssboss.shop/api/v1

Формат: JSON

Маршрутҳо: server_code/routes/api.php

Гурӯҳҳо: /api/v1/*, /api/admin/*

Auth

Аутентификатсия

МетодEndpointТавсиф
POST/user/signinВуруд → Bearer token
POST/user/signupСабти ном
POST/user/fcm-tokenFCM push (Bearer)
 
Authorization: Bearer {token}
GET /api/v1/cart/by-user?user_token=g_...

Каталог (оммавӣ)

МетодEndpointТавсиф

GET/productsРӯйхати маҳсулот
GET/product/{id}Корти маҳсулот
GET/search?q=Ҷустуҷӯ

Cart

Сабад

  • GET /cart/by-user
  • POST /cart/action
  • DELETE /cart/delete/{id}

Orders

Фармоишҳо

  • POST /order/by-user — рӯйхат/тафсилот
  • POST /order/action — ҷойгиркунӣ
  • POST /cancellation/cancel-order — бекоркунӣ

Flutter

Клиенти мобилӣ

  • lib/core/api_client.dart — Dio + Bearer
  • lib/core/config.dart — URL ва tokenҳо
  • Guest: user_token=g_{timestamp}_{random}
  • Override: .env → API_BASE_URL

Setup

Танзими локалӣ

Laravel

  • .env.example → .env
  • php artisan migrate
  • php artisan passport:install

Flutter

  • flutter pub get
  • .env: API_BASE_URL, AES_KEY, AES_IV
